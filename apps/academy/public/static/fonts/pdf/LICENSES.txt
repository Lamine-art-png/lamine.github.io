Fonts used to print learner names on AGRO-AI Academy certificate PDFs
=====================================================================

The PDF writer embeds only the glyphs a name needs (a subset) in each
certificate. These files are served as static assets and are not used to
style web pages.

| File                        | Font                         | License                                                |
|-----------------------------|------------------------------|--------------------------------------------------------|
| DejaVuSerif-Bold.ttf        | DejaVu Serif Bold            | Bitstream Vera / DejaVu free license (below)           |
| DejaVuSans-Bold.ttf         | DejaVu Sans Bold             | Bitstream Vera / DejaVu free license (below)           |
| FreeSerif.ttf               | GNU FreeFont FreeSerif       | GPL-3+ with the FreeFont font exception (below)        |
| FreeSerifBold.ttf           | GNU FreeFont FreeSerif Bold  | GPL-3+ with the FreeFont font exception (below)        |
| WenQuanYiZenHei-Names.ttf   | WenQuanYi Zen Hei (subset)   | GPL-2 with font embedding exception, M+ FONTS License   |

WenQuanYiZenHei-Names.ttf is a modified version of wqy-zenhei.ttc (face 0):
it keeps the CJK ideographs, kana, Hangul, Bopomofo and punctuation glyphs
and drops vertical-layout tables. It was produced with
apps/academy/src/lib/ttf.js (subsetFont). As permitted by the license, the
font embedding exception is extended to this modified version.

Sources: DejaVu https://dejavu-fonts.github.io/ · GNU FreeFont
https://savannah.gnu.org/projects/freefont/ · WenQuanYi http://wenq.org/
The fonts were taken from the Ubuntu packages fonts-dejavu-core,
fonts-freefont-ttf and fonts-wqy-zenhei; their copyright files follow.
