1. ကျွန်ုပ်တို့ စုဆောင်းထားသော အချက်အလက်

ကျွန်ုပ်တို့သည် အောက်ပါ အချက်အလက်အမျိုးအစားများကို စုဆောင်းနိုင်ပါသည်။

ဆက်သွယ်ရန်နှင့် အကောင့်အချက်အလက်

၎င်းတွင် သင့်အမည်၊ အီးမေးလ်လိပ်စာ၊ ကုမ္ပဏီ သို့မဟုတ် အဖွဲ့အစည်း၊ အလုပ်ခေါင်းစဉ်၊ ဖုန်းနံပါတ်၊ တည်နေရာ၊ အကောင့်အထောက်အထားများနှင့် AGRO-AI နှင့် ဆက်သွယ်မှုများ ပါဝင်နိုင်သည်။

အဖွဲ့ အစည်းနှင့် လယ်ယာကိစ္စ

၎င်းတွင် စိုက်ဧက၊ ဒေသ၊ သီးနှံအခြေအနေ၊ လယ်ယာ သို့မဟုတ် ခရိုင်အချက်အလက်များ၊ အသုံးပြုထားသော ဆည်မြောင်းစနစ်များ၊ လည်ပတ်မှုလိုအပ်ချက်များနှင့် သင်စတင်အသုံးပြုသည့်ပုံစံများ၊ သရုပ်ပြတောင်းဆိုမှုများ၊ ပံ့ပိုးမှုတောင်းဆိုမှုများ သို့မဟုတ် လုပ်ငန်းလည်ပတ်မှုပုံစံများမှတစ်ဆင့် သင်တင်ပြသည့်အချက်အလက်များ ပါဝင်နိုင်သည်။

စိုက်ပျိုးရေးနှင့် လုပ်ငန်းလည်ပတ်မှု အချက်အလက်

ဖောက်သည် သို့မဟုတ် အသုံးပြုသူမှ ခွင့်ပြုသည့်အခါ၊ AGRO-AI နယ်ပယ်နယ်နိမိတ်များ၊ ထိန်းချုပ်ကိရိယာဒေတာ၊ ဆည်မြောင်းမှတ်တမ်းများ၊ စက်ကိရိယာ သို့မဟုတ် စက်ဒေတာ၊ အလုပ်မှတ်တမ်းများ၊ အလုပ်ရလဒ်များ၊ ရာသီဥတုဒေတာ၊ ဂြိုလ်တု သို့မဟုတ် အဝေးမှ အာရုံခံဒေတာ၊ သီးနှံအခြေအနေ၊ အစီရင်ခံချက်မှတ်တမ်းများ၊ လိုက်နာမှုဆိုင်ရာ အထောက်အထားများနှင့် အခြားလုပ်ငန်းဆောင်ရွက်မှုဆိုင်ရာ အချက်အလက်များကို ပံ့ပိုးပေးရန် လိုအပ်ပါသည်။

ပေါင်းစပ်ဒေတာ

ပြင်ပကုမ္ပဏီစနစ်များကို သင်ချိတ်ဆက်သည့်အခါ၊ AGRO-AI သင်ခွင့်ပြုထားသောခွင့်ပြုချက်များအပေါ်အခြေခံ၍ အဆိုပါစနစ်များမှ ဒေတာများကို လက်ခံရရှိနိုင်ပါသည်။ ၎င်းတွင် ဆည်မြောင်းစနစ်များ၊ လယ်ယာစီမံခန့်ခွဲမှုစနစ်များ၊ စက်ကိရိယာပလက်ဖောင်းများ၊ ရာသီဥတုဝန်ဆောင်မှုပေးသူများ၊ ဂြိုလ်တု သို့မဟုတ် ပထဝီဝင်ဆိုင်ရာဝန်ဆောင်မှုပေးသူများ၊ လိုက်နာမှုစနစ်များ၊ စာရင်းဇယားများ၊ API များနှင့် အခြားချိတ်ဆက်ထားသောကိရိယာများမှ ဒေတာများ ပါဝင်နိုင်သည်။

အသုံးပြုမှုနှင့် နည်းပညာဆိုင်ရာအချက်အလက်များ

IP လိပ်စာ၊ စက်အမျိုးအစား၊ ဘရောက်ဆာအမျိုးအစား၊ ကြည့်ရှုခဲ့သည့် စာမျက်နှာများ၊ လုပ်ဆောင်ချက်များ၊ အချိန်တံဆိပ်တုံးများ၊ မှတ်တမ်းများ၊ ရောဂါရှာဖွေရေးအချက်အလက်နှင့် စနစ်စွမ်းဆောင်ရည်ဒေတာတို့အပါအဝင် ကျွန်ုပ်တို့၏ဝဘ်ဆိုက်၊ ပေါ်တယ်၊ API နှင့် ဝန်ဆောင်မှုများနှင့် သင်တုံ့ပြန်ပုံနှင့် တုံ့ပြန်ပုံအကြောင်း အချက်အလက်များကို ကျွန်ုပ်တို့ စုဆောင်းနိုင်ပါသည်။

ငွေပေးချေမှုနှင့် ငွေပေးချေမှုအချက်အလက်

အခပေးဝန်ဆောင်မှုများကို အသုံးပြုပါက၊ ကျွန်ုပ်တို့၏ ငွေပေးချေမှု သို့မဟုတ် ငွေပေးချေမှု ဝန်ဆောင်မှုပေးသူများမှ ငွေပေးချေမှု အချက်အလက်ကို စီမံဆောင်ရွက်နိုင်ပါသည်။ AGRO-AI တိကျသော လုပ်ငန်းအစီအစဉ်အတွက် အတိအလင်း မလိုအပ်ပါက ငွေပေးချေကတ်နံပါတ်များကို အပြည့်အစုံ သိမ်းဆည်းရန် မလိုအပ်ပါ။

2. ကျွန်ုပ်တို့သည် သတင်းအချက်အလက်ကို မည်သို့အသုံးပြုမည်နည်း။

AGRO-AI သတင်းအချက်အလက်ကို အသုံးပြုသည်-

  • ကျွန်ုပ်တို့၏ဝဘ်ဆိုဒ်၊ လုပ်ငန်းပေါ်တယ်၊ APIs၊ ပေါင်းစည်းမှု၊ အစီရင်ခံစာများနှင့် ပံ့ပိုးမှုများကို ပံ့ပိုးပေးခြင်း၊ လည်ပတ်ခြင်း၊ လုံခြုံအောင် နှင့် မြှင့်တင်ပါ။
  • ဝယ်ယူသူခွင့်ပြုထားသော စိုက်ပျိုးရေးစနစ်များကို ချိတ်ဆက်ကာ လုပ်ငန်းဆောင်ရွက်မှုဆိုင်ရာ အချက်အလက်၊
  • ဆည်မြောင်းဆိုင်ရာ အသိဉာဏ်၊ ရေအသုံးပြုမှုဆိုင်ရာ ထိုးထွင်းသိမြင်မှု၊ ကွင်းဆင်းလုပ်ဆောင်မှုများ မြင်နိုင်စွမ်း၊
  • စိုက်ပျိုးရေးလုပ်ငန်းအသွားအလာတစ်လျှောက်တွင် အကြံပြုထားသော၊ စီစဉ်ထားသော၊ အသုံးချ၊ အတည်ပြုခြင်း သို့မဟုတ် အစီရင်ခံထားသည်ကို နားလည်ပါ။
  • သုံးစွဲသူများ၊ ဖောက်သည်များ၊ အလားအလာများ၊ လုပ်ဖော်ကိုင်ဖက်များနှင့် ပံ့ပိုးကူညီရေးအဆက်အသွယ်များနှင့် ဆက်သွယ်ပါ။
  • စတင်အသုံးပြုသည့်ပုံစံများ၊ သရုပ်ပြတောင်းဆိုမှုများ၊ နည်းပညာဆိုင်ရာမေးခွန်းများနှင့် ဖောက်သည်ပံ့ပိုးမှုလိုအပ်ချက်များကို တုံ့ပြန်ပါ။
  • စနစ်လုံခြုံရေးကို စောင့်ကြည့်ခြင်း၊ အလွဲသုံးစားလုပ်ခြင်းမှ ကာကွယ်ရန်နှင့် နည်းပညာဆိုင်ရာ ပြဿနာများကို အမှားရှာပါ။
  • AGRO-AI ထုတ်ကုန်များ၊ အလုပ်အသွားအလာများ၊ မော်ဒယ်များနှင့် အခြေခံအဆောက်အဦများ တိုးတက်ကောင်းမွန်အောင်၊
  • ဥပဒေ၊ စာချုပ်၊ လုံခြုံရေး၊ နှင့် လုပ်ငန်းဆောင်ရွက်မှုဆိုင်ရာ တာဝန်များကို လိုက်နာပါ။

3. ဝယ်ယူသူ-ခွင့်ပြုချက်ဖြင့် ပေါင်းစပ်မှုများ

AGRO-AI သည် အသုံးပြုပြီးသား စနစ်များနှင့် အလုပ်လုပ်ရန် ဒီဇိုင်းထုတ်ထားသည်။ သင်သည် ပြင်ပကုမ္ပဏီပလပ်ဖောင်းကို ချိတ်ဆက်သောအခါ၊ သင်သည် AGRO-AI ထိုချိတ်ဆက်မှုမှ ခွင့်ပြုထားသော ဒေတာကို ရယူပြီး လုပ်ဆောင်ရန် သင်ခွင့်ပြုပါသည်။

ပြင်ပအဖွဲ့အစည်းစနစ်များကို ချိတ်ဆက်ရန်၊ ဒေတာတင်သွင်းရန်နှင့် ထိုဒေတာကို လုပ်ဆောင်ရန် AGRO-AI လုပ်ပိုင်ခွင့်နှင့် ခွင့်ပြုချက်များ လိုအပ်ကြောင်း သေချာစေရန်အတွက် သင့်တွင် တာဝန်ရှိပါသည်။
