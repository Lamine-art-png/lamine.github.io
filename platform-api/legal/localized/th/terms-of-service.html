AGRO-AI ข้อกำหนดในการให้บริการ

วันที่มีผลบังคับใช้: 3 กรกฎาคม 2026

ข้อกำหนดในการให้บริการเหล่านี้ควบคุมการเข้าถึงและการใช้งานเว็บไซต์ AGRO-AI แบบฟอร์ม พอร์ทัลองค์กร API การบูรณาการ รายงาน คำแนะนำ ขั้นตอนการทำงาน และบริการที่เกี่ยวข้อง

โดยการเข้าถึงหรือใช้บริการ AGRO-AI แสดงว่าคุณยอมรับข้อกำหนดเหล่านี้ หากคุณใช้ AGRO-AI ในนามของบริษัท ฟาร์ม เขตแหล่งน้ำ หน่วยงาน องค์กร หรือองค์กรอื่นๆ คุณรับรองว่าคุณมีอำนาจในการผูกมัดองค์กรนั้น

1. บริการ AGRO-AI

AGRO-AI สร้างซอฟต์แวร์อัจฉริยะด้านการเกษตรระดับองค์กร บริการนี้ได้รับการออกแบบมาเพื่อช่วยให้ทีมการเกษตรสามารถเชื่อมต่อระบบที่กระจัดกระจาย และเปลี่ยนข้อมูลการปฏิบัติงานให้เป็นคำแนะนำ การรายงาน การมองเห็นขั้นตอนการทำงาน บันทึกการสนับสนุนการปฏิบัติตามข้อกำหนด และข้อมูลการตัดสินใจ

AGRO-AI อาจสนับสนุนขั้นตอนการทำงานที่เกี่ยวข้องกับข่าวกรองการชลประทาน การรายงานการใช้น้ำ การปฏิบัติงานภาคสนาม ข้อมูลเครื่องจักรหรืออุปกรณ์ ข้อมูลตัวควบคุม บันทึกฟาร์ม ข้อมูลสภาพอากาศ ข้อมูลดาวเทียม บริบทของพืชผล หลักฐานการปฏิบัติตามข้อกำหนด และการรายงานขององค์กร

2. บัญชีและการเข้าถึง

คุณมีหน้าที่รับผิดชอบในการรักษาข้อมูลบัญชีที่ถูกต้อง ปกป้องข้อมูลประจำตัวของคุณ และควบคุมผู้ที่สามารถเข้าถึงพื้นที่ทำงาน AGRO-AI ขององค์กรของคุณ

คุณต้องรับผิดชอบต่อกิจกรรมทั้งหมดภายใต้บัญชีของคุณ เว้นแต่กิจกรรมนั้นเป็นผลมาจาก AGRO-AI ล้มเหลวในการปฏิบัติตามภาระผูกพันด้านความปลอดภัยของตัวเอง

3. ข้อมูลลูกค้าและการอนุญาต

คุณยังคงเป็นเจ้าของข้อมูลที่คุณส่ง อัปโหลด เชื่อมต่อ หรืออนุญาตให้ AGRO-AI ประมวลผล

คุณให้สิทธิ์ AGRO-AI ในการเข้าถึง ใช้ ประมวลผล ส่ง จัดเก็บ วิเคราะห์ และแสดงข้อมูลลูกค้าตามที่จำเป็นเพื่อมอบ รักษาความปลอดภัย สนับสนุน และปรับปรุงบริการ

คุณรับรองว่าคุณมีสิทธิ์ การอนุญาต และอำนาจที่จำเป็นในการส่งข้อมูลไปยัง AGRO-AI และเพื่อเชื่อมต่อระบบของบุคคลที่สาม รวมถึงระบบการจัดการฟาร์ม แพลตฟอร์มการชลประทาน แพลตฟอร์มอุปกรณ์ API สเปรดชีต ระบบการรายงาน และเครื่องมืออื่น ๆ

4. การบูรณาการของบุคคลที่สาม

AGRO-AI อาจเชื่อมต่อกับระบบของบุคคลที่สามตามคำขอของลูกค้า การบูรณาการเหล่านี้อาจขึ้นอยู่กับ API ของบุคคลที่สาม สิทธิ์ สถานะการออนไลน์ เงื่อนไข กระบวนการตรวจสอบ ความพร้อมใช้งานของข้อมูล และข้อจำกัดทางเทคนิค

AGRO-AI จะไม่รับผิดชอบต่อแพลตฟอร์มของบุคคลที่สาม การหยุดทำงาน API การเปลี่ยนแปลง ความไม่ถูกต้องของข้อมูล ข้อจำกัดการอนุญาต หรือข้อกำหนดของบุคคลที่สาม

การอ้างอิงถึงระบบของบุคคลที่สาม รวมถึง John Deere Operations Center, WiseConn, Talgil, Ranch Systems, OpenET หรือแพลตฟอร์มอื่นๆ ไม่ได้หมายความถึงหุ้นส่วน การรับรอง การรับรอง หรือความร่วมมือ เว้นแต่จะมีการระบุไว้อย่างชัดแจ้งเป็นลายลักษณ์อักษรโดย AGRO-AI และบุคคลที่สาม ปาร์ตี้

5. การตัดสินใจและความรับผิดชอบทางการเกษตร

AGRO-AI มีซอฟต์แวร์สนับสนุนการตัดสินใจ การวิเคราะห์ คำแนะนำ รายงาน และเครื่องมือขั้นตอนการทำงาน AGRO-AI ไม่ได้แทนที่วิจารณญาณทางวิชาชีพ การสังเกตภาคสนาม ความเชี่ยวชาญทางการเกษตร การทบทวนทางวิศวกรรม คำแนะนำทางกฎหมาย การทบทวนกฎระเบียบ หรือความรับผิดชอบในการปฏิบัติงาน

ผู้ใช้มีหน้าที่ตรวจสอบเอาต์พุต AGRO-AI ก่อนที่จะดำเนินการ

การชลประทาน การใช้น้ำ อุปกรณ์ การปฏิบัติงานภาคสนาม การปฏิบัติตามข้อกำหนด และการตัดสินใจด้านการจัดการทรัพยากรอาจได้รับผลกระทบจากสภาพอากาศ ดิน สภาพพืชผล ข้อจำกัดของโครงสร้างพื้นฐาน กฎเกณฑ์ท้องถิ่น คุณภาพของข้อมูล และการตัดสินของมนุษย์ AGRO-AI เอาต์พุตควรได้รับการตรวจสอบก่อนนำไปใช้งาน

6. ขั้นตอนการทำงานสนับสนุนการปฏิบัติตามข้อกำหนด

AGRO-AI อาจช่วยจัดระเบียบข้อมูล สร้างรายงาน เตรียมหลักฐาน และสนับสนุนขั้นตอนการทำงานการปฏิบัติตามกฎระเบียบ AGRO-AI ไม่รับประกันการปฏิบัติตามกฎระเบียบ การอนุมัติการตรวจสอบ การอนุมัติใบอนุญาต ความเพียงพอทางกฎหมาย หรือการยอมรับจากหน่วยงาน เขต หน่วยงานกำกับดูแล ลูกค้า หรือบุคคลที่สาม

ผู้ใช้ยังคงรับผิดชอบต่อการตรวจสอบขั้นสุดท้าย การส่ง การรับรอง และการตัดสินใจด้านการปฏิบัติตามข้อกำหนด

7. การใช้งานที่ยอมรับได้

คุณไม่สามารถใช้บริการ AGRO-AI เพื่อ:

  • ละเมิดกฎหมาย ข้อบังคับ หรือสิทธิ์ของบุคคลที่สาม
  • เข้าถึงระบบหรือข้อมูลโดยไม่ได้รับอนุญาต
  • แทรกแซงการรักษาความปลอดภัยของบริการ ความพร้อมใช้งาน หรือความสมบูรณ์
  • ทำวิศวกรรมย้อนกลับ ขูด โอเวอร์โหลด หรือโจมตีระบบ AGRO-AI
  • ส่งรหัสที่เป็นอันตรายหรือเนื้อหาที่เป็นอันตราย
  • บิดเบือนความจริง AGRO-AI เอาต์พุตว่าเป็นผลลัพธ์ที่รับประกัน
  • ใช้ AGRO-AI เพื่อตัดสินใจในการปฏิบัติงานที่ไม่ปลอดภัยโดยไม่ได้รับการตรวจสอบจากมนุษย์อย่างเหมาะสม
  • ขายต่อหรืออนุญาตช่วง AGRO-AI บริการ เว้นแต่จะได้รับอนุญาตอย่างชัดแจ้ง

8. ค่าธรรมเนียมและการสมัครสมาชิก

บริการแบบชำระเงิน การนำร่อง การใช้งานระดับองค์กร การรวมระบบ หรืองานแบบกำหนดเองอาจอยู่ภายใต้แบบฟอร์มคำสั่งซื้อ ข้อตกลงการสมัครสมาชิก ข้อตกลงการนำร่อง คำชี้แจงการทำงาน หรือข้อตกลงเป็นลายลักษณ์อักษรที่แยกต่างหาก

หากมีค่าธรรมเนียม แสดงว่าคุณตกลงที่จะชำระเงินตามข้อตกลงที่เกี่ยวข้อง ค่าธรรมเนียมอาจไม่สามารถขอคืนได้เว้นแต่จะระบุไว้เป็นอย่างอื่นเป็นลายลักษณ์อักษร

9. ทรัพย์สินทางปัญญา

AGRO-AI และผู้ออกใบอนุญาตยังคงเป็นเจ้าของแพลตฟอร์ม ซอฟต์แวร์ แบบจำลอง ขั้นตอนการทำงาน ส่วนติดต่อผู้ใช้ เอกสาร การออกแบบ เครื่องหมายการค้า และเทคโนโลยีพื้นฐาน AGRO-AI

คุณไม่สามารถคัดลอก แก้ไข แจกจ่าย หรือสร้างผลงานลอกเลียนจากเทคโนโลยี AGRO-AI เว้นแต่จะได้รับอนุญาตตามข้อกำหนดเหล่านี้หรือข้อตกลงเป็นลายลักษณ์อักษร

ข้อมูลลูกค้ายังคงเป็นของลูกค้าหรือฝ่ายที่ส่งหรืออนุญาต

10. ข้อเสนอแนะ

หากคุณให้คำแนะนำ แนวคิด คำขอคุณลักษณะ หรือข้อเสนอแนะ AGRO-AI อาจนำไปใช้โดยไม่มีข้อจำกัดหรือค่าตอบแทน หากเราไม่เปิดเผยข้อมูลที่เป็นความลับของคุณซึ่งเป็นการละเมิดข้อตกลงที่เกี่ยวข้อง

11. การรักษาความลับ

ข้อมูลบางอย่างที่มีการแลกเปลี่ยนระหว่าง AGRO-AI และลูกค้าอาจเป็นความลับ รวมถึงข้อมูลทางเทคนิค แผนธุรกิจ แผนงานผลิตภัณฑ์ ข้อมูลลูกค้า รายละเอียดการบูรณาการ ราคา และขั้นตอนการทำงานที่ไม่ใช่แบบสาธารณะ

แต่ละฝ่ายควรใช้ความระมัดระวังตามสมควรในการปกป้องข้อมูลที่เป็นความลับ และใช้เพื่อวัตถุประสงค์ของความสัมพันธ์เท่านั้น

12. คุณสมบัติเบต้า นักบิน และระยะเปิดตัว

คุณลักษณะบางอย่าง AGRO-AI อาจอยู่ในสถานะเบต้า นำร่อง ดูตัวอย่าง การประเมินผล หรือสถานะระยะการเปิดตัว คุณลักษณะดังกล่าวอาจมีการเปลี่ยนแปลง ล่าช้า ถูกยกเลิก หรือมีข้อผิดพลาด

AGRO-AI อาจแก้ไขคุณสมบัติในขณะที่ปรับปรุงผลิตภัณฑ์ ผสานรวมกับระบบของบุคคลที่สาม ตอบสนองต่อความต้องการของลูกค้า หรือตรงตามข้อกำหนดด้านความปลอดภัย การปฏิบัติตามข้อกำหนด หรือการปฏิบัติงาน

13. การปฏิเสธความรับผิดชอบ

AGRO-AI มีให้ "ตามสภาพ" และ "ตามที่มี" ตามขอบเขตสูงสุดที่กฎหมายอนุญาต

AGRO-AI ไม่รับประกันว่าบริการจะไม่หยุดชะงัก ปราศจากข้อผิดพลาด หรือคำแนะนำ รายงาน การบูรณาการ การคาดการณ์ หรือผลลัพธ์ของเวิร์กโฟลว์ทั้งหมดจะสมบูรณ์ ถูกต้อง หรือเหมาะสมกับวัตถุประสงค์ในการดำเนินงานทุกประการ

14. ข้อจำกัดความรับผิด

ตามขอบเขตสูงสุดที่กฎหมายอนุญาต AGRO-AI จะไม่รับผิดชอบต่อความเสียหายทางอ้อม ความเสียหายพิเศษ เป็นผลสืบเนื่อง ที่เป็นแบบอย่าง หรือเชิงลงโทษ รวมถึงการสูญเสียผลกำไร รายได้ที่สูญเสีย ข้อมูลสูญหาย การสูญเสียพืชผล ผลที่ตามมาของการจัดสรรน้ำ การลงโทษตามกฎระเบียบ หรือการหยุดชะงักทางธุรกิจ

ภายในขอบเขตสูงสุดที่กฎหมายอนุญาต ความรับผิดทั้งหมดของ AGRO-AI สำหรับการเรียกร้องที่เกี่ยวข้องกับบริการจะไม่เกินจำนวนเงินที่ลูกค้าจ่ายให้กับ AGRO-AI สำหรับบริการที่ก่อให้เกิดการเรียกร้องในช่วงสิบสองเดือนก่อนการเรียกร้อง หรือหนึ่งร้อยดอลลาร์หากไม่มีการชำระค่าธรรมเนียม
