1. ข้อมูลที่เรารวบรวม

เราอาจรวบรวมข้อมูลประเภทต่อไปนี้:

ข้อมูลการติดต่อและบัญชี

ซึ่งอาจรวมถึงชื่อ ที่อยู่อีเมล บริษัทหรือองค์กร ตำแหน่งงาน หมายเลขโทรศัพท์ สถานที่ตั้ง ข้อมูลประจำตัวบัญชี และการสื่อสารกับ AGRO-AI

องค์กรและบริบทฟาร์ม

ซึ่งอาจรวมถึงเอเคอร์ ภูมิภาค บริบทของพืชผล ข้อมูลฟาร์มหรือเขต ระบบชลประทานที่ใช้ ข้อกำหนดในการปฏิบัติงาน และข้อมูลที่คุณส่งผ่านแบบฟอร์มการเริ่มต้นใช้งาน คำขอสาธิต คำขอการสนับสนุน หรือเวิร์กโฟลว์ขององค์กร

ข้อมูลการเกษตรและการดำเนินงาน

เมื่อได้รับอนุญาตจากลูกค้าหรือผู้ใช้ AGRO-AI อาจประมวลผลข้อมูลการดำเนินงานทางการเกษตร รวมถึงขอบเขตของสนาม ข้อมูลตัวควบคุม บันทึกการชลประทาน อุปกรณ์หรือข้อมูลเครื่องจักร บันทึกการทำงาน ผลงาน ข้อมูลสภาพอากาศ ข้อมูลดาวเทียมหรือการสำรวจระยะไกล บริบทของพืชผล บันทึกการรายงาน หลักฐานการปฏิบัติตามข้อกำหนด และข้อมูลการปฏิบัติงานอื่น ๆ ที่จำเป็นในการให้บริการ

ข้อมูลการรวม

เมื่อคุณเชื่อมต่อระบบของบุคคลที่สาม AGRO-AI อาจได้รับข้อมูลจากระบบเหล่านั้นตามสิทธิ์ที่คุณอนุมัติ ซึ่งอาจรวมถึงข้อมูลจากระบบชลประทาน ระบบการจัดการฟาร์ม แพลตฟอร์มอุปกรณ์ ผู้ให้บริการสภาพอากาศ ผู้ให้บริการดาวเทียมหรือภูมิสารสนเทศ ระบบการปฏิบัติตามข้อกำหนด สเปรดชีต API และเครื่องมือที่เชื่อมต่ออื่นๆ

การใช้งานและข้อมูลทางเทคนิค

เราอาจรวบรวมข้อมูลเกี่ยวกับวิธีการที่คุณโต้ตอบกับเว็บไซต์ พอร์ทัล API และบริการของเรา รวมถึงที่อยู่ IP ประเภทอุปกรณ์ ประเภทเบราว์เซอร์ หน้าที่ดู การดำเนินการที่ดำเนินการ การประทับเวลา บันทึก ข้อมูลการวินิจฉัย และข้อมูลประสิทธิภาพของระบบ

ข้อมูลการชำระเงินและการเรียกเก็บเงิน

หากใช้บริการแบบชำระเงิน ข้อมูลการเรียกเก็บเงินอาจได้รับการประมวลผลโดยผู้ให้บริการชำระเงินหรือเรียกเก็บเงินของเรา AGRO-AI ไม่จำเป็นต้องจัดเก็บหมายเลขบัตรชำระเงินแบบเต็ม เว้นแต่จะกำหนดไว้อย่างชัดแจ้งสำหรับการจัดการองค์กรโดยเฉพาะ

2. วิธีที่เราใช้ข้อมูล

AGRO-AI ใช้ข้อมูลเพื่อ:

  • จัดหา ดำเนินการ รักษาความปลอดภัย และปรับปรุงเว็บไซต์ พอร์ทัลองค์กร API การบูรณาการ รายงาน และการสนับสนุนของเรา
  • เชื่อมต่อระบบการเกษตรที่ได้รับอนุญาตจากลูกค้าและข้อมูลการปฏิบัติงานของกระบวนการ
  • สร้างข่าวกรองด้านการชลประทาน ข้อมูลเชิงลึกเกี่ยวกับการใช้น้ำ การมองเห็นการปฏิบัติงานภาคสนาม ขั้นตอนการทำงานสนับสนุนการปฏิบัติตามกฎระเบียบ และรายงานขององค์กร
  • ทำความเข้าใจกับสิ่งที่แนะนำ กำหนดเวลา ประยุกต์ ตรวจสอบ หรือรายงานในขั้นตอนการทำงานทางการเกษตร
  • สื่อสารกับผู้ใช้ ลูกค้า ผู้มีโอกาสเป็นลูกค้า คู่ค้า และผู้ติดต่อฝ่ายสนับสนุน
  • ตอบกลับแบบฟอร์มการเริ่มต้นใช้งาน คำขอสาธิต คำถามทางเทคนิค และความต้องการการสนับสนุนลูกค้า
  • ตรวจสอบความปลอดภัยของระบบ ป้องกันการใช้งานในทางที่ผิด และแก้ไขปัญหาทางเทคนิค
  • ปรับปรุง AGRO-AI ผลิตภัณฑ์ ขั้นตอนการทำงาน แบบจำลอง และโครงสร้างพื้นฐาน
  • ปฏิบัติตามข้อผูกพันทางกฎหมาย สัญญา การรักษาความปลอดภัย และการปฏิบัติงาน

3. การบูรณาการที่ได้รับอนุญาตจากลูกค้า

AGRO-AI ได้รับการออกแบบมาเพื่อทำงานร่วมกับระบบที่ลูกค้าใช้งานอยู่แล้ว เมื่อคุณเชื่อมต่อแพลตฟอร์มของบุคคลที่สาม คุณอนุญาตให้ AGRO-AI เข้าถึงและประมวลผลข้อมูลที่ได้รับอนุญาตจากการเชื่อมต่อนั้น

คุณมีหน้าที่รับผิดชอบในการตรวจสอบให้แน่ใจว่าคุณมีสิทธิ์และการอนุญาตที่จำเป็นในการเชื่อมต่อระบบของบุคคลที่สาม ส่งข้อมูล และให้สิทธิ์ AGRO-AI เพื่อประมวลผลข้อมูลนั้น

AGRO-AI ไม่ได้ควบคุมแพลตฟอร์มของบุคคลที่สาม อาจมีข้อกำหนด การอนุญาต API แนวทางปฏิบัติด้านข้อมูล และความพร้อมใช้งานของตนเอง

4. AI การวิเคราะห์ และการใช้โมเดล

AGRO-AI ใช้ข้อมูลเพื่อสร้างข่าวกรองทางการเกษตร คำแนะนำ การวิเคราะห์ การรายงาน และการสนับสนุนขั้นตอนการทำงาน

AGRO-AI ไม่ขายข้อมูลการดำเนินงานของลูกค้า

AGRO-AI ไม่ใช้ข้อมูลการปฏิบัติงานของลูกค้าที่สามารถระบุตัวตนได้เพื่อฝึกอบรมโมเดลพื้นฐานของบุคคลที่สามที่ไม่เกี่ยวข้อง เว้นแต่จะได้รับอนุญาตจากลูกค้าหรือจำเป็นต้องให้บริการที่ร้องขอภายใต้การป้องกันที่เหมาะสม

เราอาจใช้ข้อมูลที่รวบรวม ไม่ระบุตัวตน หรือไม่ระบุตัวตนเพื่อปรับปรุงประสิทธิภาพของผลิตภัณฑ์ การวัดประสิทธิภาพ การวิเคราะห์ ความน่าเชื่อถือของโครงสร้างพื้นฐาน และคุณภาพการบริการ โดยที่ข้อมูลดังกล่าวไม่ได้ระบุลูกค้า ผู้ใช้ หรือการดำเนินงานที่เฉพาะเจาะจง

5. เราแบ่งปันข้อมูลอย่างไร

AGRO-AI อาจแบ่งปันข้อมูลกับ:

ผู้ให้บริการ

เราอาจใช้ผู้จำหน่ายสำหรับการโฮสต์ การวิเคราะห์ ความปลอดภัย โครงสร้างพื้นฐาน การสื่อสาร การสนับสนุน การเรียกเก็บเงิน และความต้องการในการดำเนินงานอื่น ๆ

การบูรณาการที่ได้รับอนุญาตจากลูกค้า

เมื่อลูกค้าเชื่อมต่อแพลตฟอร์มของบุคคลที่สามหรือร้องขอเวิร์กโฟลว์การบูรณาการ ข้อมูลอาจถูกแลกเปลี่ยนกับระบบนั้นตามความจำเป็นเพื่อให้บริการ

ลูกค้าองค์กรและผู้ใช้ที่ได้รับอนุญาต

ข้อมูลอาจปรากฏแก่ผู้ใช้ที่ได้รับอนุญาตภายในองค์กร บัญชี โครงการ ฟาร์ม อำเภอ หรือพื้นที่ทำงานขององค์กรเดียวกัน

วัตถุประสงค์ทางกฎหมายและความปลอดภัย

เราอาจเปิดเผยข้อมูลหากจำเป็นต้องปฏิบัติตามกฎหมาย บังคับใช้ข้อตกลง ปกป้องสิทธิ์และความปลอดภัย ตรวจสอบการใช้ในทางที่ผิด หรือตอบสนองต่อคำร้องขอทางกฎหมาย

การโอนกิจการ

หาก AGRO-AI เกี่ยวข้องกับการควบรวมกิจการ การเข้าซื้อกิจการ การจัดหาเงินทุน การปรับโครงสร้างองค์กร หรือการขายสินทรัพย์ ข้อมูลอาจถูกถ่ายโอนโดยเป็นส่วนหนึ่งของธุรกรรมนั้น โดยอยู่ภายใต้การคุ้มครองที่เหมาะสม

6. คุกกี้และการวิเคราะห์

AGRO-AI อาจใช้คุกกี้ เครื่องมือวิเคราะห์ และเทคโนโลยีที่คล้ายกันเพื่อใช้งานเว็บไซต์ จดจำการตั้งค่า ทำความเข้าใจการใช้งาน ปรับปรุงประสิทธิภาพ และปกป้องความปลอดภัย ผู้ใช้สามารถปรับการตั้งค่าเบราว์เซอร์เพื่อจำกัดคุกกี้ แม้ว่าคุณสมบัติบางอย่างอาจทำงานไม่ถูกต้องหากไม่มีคุกกี้ก็ตาม

7. การเก็บรักษาข้อมูล

AGRO-AI เก็บรักษาข้อมูลไว้นานเท่าที่จำเป็นเพื่อให้บริการ ปฏิบัติตามภาระผูกพันทางกฎหมายหรือตามสัญญา แก้ไขข้อพิพาท รักษาความปลอดภัย สนับสนุนการตรวจสอบ และดำเนินธุรกิจ

ข้อมูลการปฏิบัติงานของลูกค้าอาจถูกเก็บรักษาไว้ตามข้อตกลงของลูกค้าที่เกี่ยวข้อง การตั้งค่าพื้นที่ทำงานขององค์กร การกำหนดค่าการรวม หรือข้อกำหนดทางกฎหมาย

8. ความปลอดภัย

AGRO-AI ใช้มาตรการด้านการบริหาร เทคนิค และองค์กรที่สมเหตุสมผลเพื่อปกป้องข้อมูล ไม่มีระบบใดที่สามารถรับประกันได้ว่าจะมีความปลอดภัยอย่างสมบูรณ์ ลูกค้าและผู้ใช้มีหน้าที่รับผิดชอบในการรักษาข้อมูลรับรองที่ปลอดภัย จัดการสิทธิ์การเข้าถึง และแจ้ง AGRO-AI ทันทีถึงการใช้งานที่ไม่ได้รับอนุญาตที่น่าสงสัย

9. การประมวลผลข้อมูลระหว่างประเทศ

AGRO-AI อาจประมวลผลข้อมูลในสหรัฐอเมริกาและสถานที่อื่น ๆ ที่เราหรือผู้ให้บริการของเราดำเนินการ ด้วยการใช้บริการ AGRO-AI คุณเข้าใจว่าข้อมูลอาจถูกประมวลผลนอกประเทศหรือภูมิภาคของคุณ โดยอยู่ภายใต้มาตรการป้องกันที่เกี่ยวข้อง

10. ทางเลือกและสิทธิ์ของคุณ

คุณอาจมีสิทธิ์ในการเข้าถึง แก้ไข ลบ จำกัด หรือคัดค้านการประมวลผลข้อมูลส่วนบุคคลของคุณ ทั้งนี้ขึ้นอยู่กับตำแหน่งของคุณ คุณอาจมีสิทธิ์ร้องขอการเคลื่อนย้ายหรือเพิกถอนความยินยอมในกรณีที่การประมวลผลขึ้นอยู่กับความยินยอม

หากต้องการส่งคำขอ โปรดติดต่อ AGRO-AI โดยใช้ข้อมูลการติดต่อด้านล่าง เราอาจจำเป็นต้องยืนยันตัวตนและอำนาจของคุณก่อนที่จะดำเนินการตามคำขอ
