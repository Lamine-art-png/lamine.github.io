AGRO-AI プライバシー ポリシー

発効日：2026年7月3日

AGRO-AI は、生産者、農場経営者、アドバイザー、給水地区、ディーラー、OEM、データ パートナー、農業企業向けのエンタープライズ農業インテリジェンス ソフトウェアを構築します。このプライバシー ポリシーでは、お客様が AGRO-AI の Web サイト、フォーム、エンタープライズ ポータル、API、統合、レポート、および関連サービスを使用する際に、当社が情報を収集、使用、開示、保護する方法について説明します。

1. 当社が収集する情報

当社は次のカテゴリの情報を収集する場合があります。

連絡先とアカウント情報

これには、お客様の名前、電子メール アドレス、会社または組織、役職、電話番号、所在地、アカウント資格情報、および AGRO-AI との通信が含まれる場合があります。

組織と農場の背景

これには、面積、地域、作物の状況、農場または地区の情報、使用される灌漑システム、動作要件、およびオンボーディング フォーム、デモ リクエスト、サポート リクエスト、またはエンタープライズ ワークフローを通じて送信される情報が含まれる場合があります。

農業および経営データ

顧客またはユーザーによって許可された場合、<<AGROAI_KEEP_0000>>> は、圃場境界、管理者データ、灌漑記録、設備または機械のデータ、作業記録、作業結果、気象データ、衛星またはリモートセンシングデータ、作物の状況、報告記録、コンプライアンスの証拠、およびサービスを提供するために必要なその他の運用情報を含む農業経営データを処理することがあります。

統合データ

サードパーティ システムに接続すると、<<AGROAI_KEEP_0001>>> は、承認した権限に基づいてそれらのシステムからデータを受信する場合があります。これには、灌漑システム、農場管理システム、機器プラットフォーム、気象プロバイダー、衛星または地理空間プロバイダー、コンプライアンス システム、スプレッドシート、API、およびその他の接続ツールからのデータが含まれる場合があります。

使用方法と技術情報

当社は、IP アドレス、デバイスの種類、ブラウザの種類、閲覧したページ、実行されたアクション、タイムスタンプ、ログ、診断情報、システム パフォーマンス データなど、お客様が当社の Web サイト、ポータル、API、およびサービスとどのようにやり取りするかに関する情報を収集する場合があります。

支払いおよび請求情報

有料サービスを使用する場合、請求情報は当社の支払いプロバイダーまたは請求プロバイダーによって処理される場合があります。 AGRO-AI は、特定の企業取り決めで明示的に要求されない限り、完全な支払いカード番号を保存する必要はありません。

2. 情報の使用方法

AGRO-AI は情報を次の目的で使用します。

  • 当社の Web サイト、エンタープライズ ポータル、API、統合、レポート、サポートを提供、運営、保護、改善するため。
  • 顧客が承認した農業システムに接続し、運用データを処理します。
  • 灌漑インテリジェンス、水利用に関する洞察、現場作業の可視性、コンプライアンス サポート ワークフロー、および企業レポートを生成します。
  • 農業ワークフロー全体で何が推奨、スケジュール、適用、検証、または報告されたかを理解します。
  • ユーザー、顧客、見込み客、パートナー、サポート連絡先とのコミュニケーション。
  • オンボーディングフォーム、デモリクエスト、技術的な質問、顧客サポートのニーズに対応します。
  • システムのセキュリティを監視し、誤用を防止し、技術的な問題をデバッグします。
  • AGRO-AI 製品、ワークフロー、モデル、インフラストラクチャを改善します。
  • 法律、契約、セキュリティ、運用上の義務を遵守します。

3. 顧客が承認した統合

AGRO-AI は、顧客がすでに使用しているシステムで動作するように設計されています。サードパーティのプラットフォームに接続すると、<<AGROAI_KEEP_0002>>> がその接続で許可されたデータにアクセスして処理することを承認したことになります。

あなたには、サードパーティ システムに接続し、データを送信し、そのデータを処理するための AGRO-AI を承認するために必要な権利と許可があることを確認する責任があります。

AGRO-AI はサードパーティのプラットフォームを制御しません。独自の条件、権限、API、データ慣行、および可用性が適用される場合があります。

4. AI、分析、モデルの使用

AGRO-AI はデータを使用して、農業インテリジェンス、推奨事項、分析、レポート、およびワークフロー サポートを生成します。

AGRO-AI は顧客の運用データを販売しません。

AGRO-AI は、顧客の許可がない限り、または適切な保護措置の下で要求されたサービスを提供する必要がある場合を除き、識別可能な顧客運用データを使用して無関係なサードパーティ基盤モデルをトレーニングすることはありません。

当社は、製品のパフォーマンス、ベンチマーク、分析、インフラストラクチャの信頼性、およびサービス品質を向上させるために、集約、匿名化、または匿名化されたデータを使用する場合がありますが、そのようなデータが特定の顧客、ユーザー、または業務を識別しない場合に限ります。

5. 情報の共有方法

AGRO-AI は以下と情報を共有する場合があります。

サービスプロバイダー

当社は、ホスティング、分析、セキュリティ、インフラストラクチャ、通信、サポート、請求、その他の運用上のニーズのためにベンダーを使用する場合があります。

顧客が承認した統合

顧客がサードパーティのプラットフォームに接続するか、統合ワークフローを要求すると、サービスを提供するために必要に応じてそのシステムと情報が交換されることがあります。

企業顧客と認定ユーザー

情報は、同じ組織、アカウント、プロジェクト、ファーム、地区、または企業ワークスペース内の承認されたユーザーに表示される場合があります。

法的および安全上の目的

当社は、法律の遵守、契約の強制、権利と安全の保護、悪用の調査、または法的要求への対応のために必要な場合、情報を開示することがあります。

事業譲渡

AGRO-AI が合併、買収、資金調達、再編、または資産の売却に関与している場合、適切な保護を条件として、その取引の一環として情報が転送される場合があります。

6. クッキーと分析

AGRO-AI は、Web サイトの運営、設定の記憶、使用状況の把握、パフォーマンスの向上、セキュリティの保護のために、Cookie、分析ツール、および同様のテクノロジーを使用する場合があります。ユーザーはブラウザの設定を調整して Cookie を制限できますが、Cookie がないと一部の機能が正しく動作しない場合があります。

7. データの保持

AGRO-AI は、サービスの提供、法的または契約上の義務の遵守、紛争の解決、セキュリティの維持、監査のサポート、および事業の運営に必要な期間、情報を保持します。

顧客の運用データは、該当する顧客契約、エンタープライズ ワークスペース設定、統合構成、または法的要件に従って保持される場合があります。

8. セキュリティ

AGRO-AI は、情報を保護するために合理的な管理上、技術上、および組織上の措置を講じます。完全に安全であることを保証できるシステムはありません。顧客とユーザーは、安全な資格情報を維持し、アクセス許可を管理し、不正使用の疑いがある場合は直ちに AGRO-AI に通知する責任があります。

9. 国際的なデータ処理

AGRO-AI は、米国および当社または当社のサービスプロバイダーが事業を展開するその他の場所で情報を処理する場合があります。 AGRO-AI サービスを使用することにより、適用される保護措置の対象となり、情報があなたの国または地域外で処理される可能性があることを理解したものとします。

10. あなたの選択と権利

あなたの所在地に応じて、あなたは自分の個人情報の特定の処理にアクセス、修正、削除、制限、または異議を唱える権利を有する場合があります。また、移植性を要求したり、処理が同意に基づいている場合は同意を撤回する権利を有する場合もあります。
