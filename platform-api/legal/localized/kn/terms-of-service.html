ಈ ಸೇವಾ ನಿಯಮಗಳು AGRO-AI ವೆಬ್‌ಸೈಟ್‌ಗಳು, ಫಾರ್ಮ್‌ಗಳು, ಎಂಟರ್‌ಪ್ರೈಸ್ ಪೋರ್ಟಲ್, API ಗಳು, ಏಕೀಕರಣಗಳು, ವರದಿಗಳು, ಶಿಫಾರಸುಗಳು, ವರ್ಕ್‌ಫ್ಲೋಗಳು ಮತ್ತು ಸಂಬಂಧಿತ ಸೇವೆಗಳಿಗೆ ನಿಮ್ಮ ಪ್ರವೇಶ ಮತ್ತು ಬಳಕೆಯನ್ನು ನಿಯಂತ್ರಿಸುತ್ತವೆ.

AGRO-AI ಸೇವೆಗಳನ್ನು ಪ್ರವೇಶಿಸುವ ಮೂಲಕ ಅಥವಾ ಬಳಸುವ ಮೂಲಕ, ನೀವು ಈ ನಿಯಮಗಳನ್ನು ಒಪ್ಪುತ್ತೀರಿ. ನೀವು ಕಂಪನಿ, ಫಾರ್ಮ್, ವಾಟರ್ ಡಿಸ್ಟ್ರಿಕ್ಟ್, ಏಜೆನ್ಸಿ, ಎಂಟರ್‌ಪ್ರೈಸ್ ಅಥವಾ ಇತರ ಸಂಸ್ಥೆಯ ಪರವಾಗಿ AGRO-AI ಅನ್ನು ಬಳಸುತ್ತಿದ್ದರೆ, ಆ ಸಂಸ್ಥೆಯನ್ನು ಬಂಧಿಸಲು ನಿಮಗೆ ಅಧಿಕಾರವಿದೆ ಎಂದು ನೀವು ಪ್ರತಿನಿಧಿಸುತ್ತೀರಿ.

1. AGRO-AI ಸೇವೆಗಳು

AGRO-AI ಎಂಟರ್‌ಪ್ರೈಸ್ ಕೃಷಿ ಗುಪ್ತಚರ ಸಾಫ್ಟ್‌ವೇರ್ ಅನ್ನು ನಿರ್ಮಿಸುತ್ತದೆ. ಕೃಷಿ ತಂಡಗಳು ವಿಘಟಿತ ವ್ಯವಸ್ಥೆಗಳನ್ನು ಸಂಪರ್ಕಿಸಲು ಮತ್ತು ಕಾರ್ಯಾಚರಣೆಯ ಡೇಟಾವನ್ನು ಶಿಫಾರಸುಗಳು, ವರದಿ ಮಾಡುವಿಕೆ, ವರ್ಕ್‌ಫ್ಲೋ ಗೋಚರತೆ, ಅನುಸರಣೆ-ಬೆಂಬಲ ದಾಖಲೆಗಳು ಮತ್ತು ನಿರ್ಧಾರ ಬುದ್ಧಿವಂತಿಕೆಯಾಗಿ ಪರಿವರ್ತಿಸಲು ಸಹಾಯ ಮಾಡಲು ಈ ಸೇವೆಯನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ.

AGRO-AI ನೀರಾವರಿ ಬುದ್ಧಿಮತ್ತೆ, ನೀರಿನ ಬಳಕೆಯ ವರದಿ, ಕ್ಷೇತ್ರ ಕಾರ್ಯಾಚರಣೆಗಳು, ಯಂತ್ರ ಅಥವಾ ಸಲಕರಣೆಗಳ ಡೇಟಾ, ನಿಯಂತ್ರಕ ಡೇಟಾ, ಕೃಷಿ ದಾಖಲೆಗಳು, ಹವಾಮಾನ ದತ್ತಾಂಶ, ಉಪಗ್ರಹ ಗುಪ್ತಚರ, ಬೆಳೆ ಸಂದರ್ಭ, ಅನುಸರಣೆ ಪುರಾವೆಗಳು ಮತ್ತು ಎಂಟರ್‌ಪ್ರೈಸ್ ವರದಿ ಮಾಡುವಿಕೆಯನ್ನು ಒಳಗೊಂಡಿರುವ ಕೆಲಸದ ಹರಿವನ್ನು ಬೆಂಬಲಿಸಬಹುದು.

2. ಖಾತೆಗಳು ಮತ್ತು ಪ್ರವೇಶ

ನಿಖರವಾದ ಖಾತೆ ಮಾಹಿತಿಯನ್ನು ನಿರ್ವಹಿಸಲು, ನಿಮ್ಮ ರುಜುವಾತುಗಳನ್ನು ರಕ್ಷಿಸಲು ಮತ್ತು ನಿಮ್ಮ ಸಂಸ್ಥೆಯ AGRO-AI ಕಾರ್ಯಸ್ಥಳಕ್ಕೆ ಯಾರು ಪ್ರವೇಶವನ್ನು ಹೊಂದಿದ್ದಾರೆ ಎಂಬುದನ್ನು ನಿಯಂತ್ರಿಸಲು ನೀವು ಜವಾಬ್ದಾರರಾಗಿರುತ್ತೀರಿ.

AGRO-AI ಚಟುವಟಿಕೆಯು ತನ್ನದೇ ಆದ ಭದ್ರತಾ ಕಟ್ಟುಪಾಡುಗಳನ್ನು ಪೂರೈಸುವಲ್ಲಿ ವಿಫಲವಾದರೆ ನಿಮ್ಮ ಖಾತೆಯ ಅಡಿಯಲ್ಲಿನ ಎಲ್ಲಾ ಚಟುವಟಿಕೆಗಳಿಗೆ ನೀವು ಜವಾಬ್ದಾರರಾಗಿರುತ್ತೀರಿ.

3. ಗ್ರಾಹಕರ ಡೇಟಾ ಮತ್ತು ಅಧಿಕಾರ

ನೀವು ಸಲ್ಲಿಸಿದ ಡೇಟಾದ ಮಾಲೀಕತ್ವವನ್ನು ನೀವು ಉಳಿಸಿಕೊಂಡಿದ್ದೀರಿ, ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, ಸಂಪರ್ಕಿಸಿ ಅಥವಾ ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲು AGRO-AI ಅನ್ನು ದೃಢೀಕರಿಸುತ್ತೀರಿ.

ಸೇವೆಗಳನ್ನು ಒದಗಿಸಲು, ಸುರಕ್ಷಿತಗೊಳಿಸಲು, ಬೆಂಬಲಿಸಲು ಮತ್ತು ಸುಧಾರಿಸಲು ಅಗತ್ಯವಿರುವಂತೆ ಗ್ರಾಹಕ ಡೇಟಾವನ್ನು ಪ್ರವೇಶಿಸಲು, ಬಳಸಲು, ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲು, ರವಾನಿಸಲು, ಸಂಗ್ರಹಿಸಲು, ವಿಶ್ಲೇಷಿಸಲು ಮತ್ತು ಪ್ರದರ್ಶಿಸಲು ನೀವು AGRO-AI ಸೀಮಿತ ಹಕ್ಕನ್ನು ನೀಡುತ್ತೀರಿ.

AGRO-AI ಗೆ ಡೇಟಾವನ್ನು ಸಲ್ಲಿಸಲು ಮತ್ತು ಕೃಷಿ ನಿರ್ವಹಣಾ ವ್ಯವಸ್ಥೆಗಳು, ನೀರಾವರಿ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು, ಸಲಕರಣೆ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು, APIಗಳು, ಸ್ಪ್ರೆಡ್‌ಶೀಟ್‌ಗಳು, ವರದಿ ಮಾಡುವ ವ್ಯವಸ್ಥೆಗಳು ಮತ್ತು ಇತರ ಪರಿಕರಗಳನ್ನು ಒಳಗೊಂಡಂತೆ ಮೂರನೇ-ಪಕ್ಷದ ವ್ಯವಸ್ಥೆಗಳನ್ನು ಸಂಪರ್ಕಿಸಲು ನೀವು ಅಗತ್ಯ ಹಕ್ಕುಗಳು, ಅನುಮತಿಗಳು ಮತ್ತು ಅಧಿಕಾರವನ್ನು ಹೊಂದಿರುವಿರಿ ಎಂದು ನೀವು ಪ್ರತಿನಿಧಿಸುತ್ತೀರಿ.

4. ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಏಕೀಕರಣಗಳು

AGRO-AI ಗ್ರಾಹಕರ ಕೋರಿಕೆಯ ಮೇರೆಗೆ ಥರ್ಡ್-ಪಾರ್ಟಿ ಸಿಸ್ಟಮ್‌ಗಳೊಂದಿಗೆ ಸಂಪರ್ಕಿಸಬಹುದು. ಈ ಏಕೀಕರಣಗಳು ಮೂರನೇ ವ್ಯಕ್ತಿಯ API ಗಳು, ಅನುಮತಿಗಳು, ಸಮಯ, ನಿಯಮಗಳು, ವಿಮರ್ಶೆ ಪ್ರಕ್ರಿಯೆಗಳು, ಡೇಟಾ ಲಭ್ಯತೆ ಮತ್ತು ತಾಂತ್ರಿಕ ಮಿತಿಗಳನ್ನು ಅವಲಂಬಿಸಿರಬಹುದು.

AGRO-AI ಮೂರನೇ ವ್ಯಕ್ತಿಯ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು, ಸ್ಥಗಿತಗಳು, API ಬದಲಾವಣೆಗಳು, ಡೇಟಾ ತಪ್ಪುಗಳು, ಅನುಮತಿ ನಿರ್ಬಂಧಗಳು ಅಥವಾ ಮೂರನೇ ವ್ಯಕ್ತಿಯ ನಿಯಮಗಳಿಗೆ ಜವಾಬ್ದಾರರಾಗಿರುವುದಿಲ್ಲ.

ಜಾನ್ ಡೀರ್ ಆಪರೇಷನ್ ಸೆಂಟರ್, WiseConn, Talgil, ರಾಂಚ್ ಸಿಸ್ಟಮ್ಸ್, OpenET, ಅಥವಾ ಇತರ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳು ಸೇರಿದಂತೆ ಮೂರನೇ-ಪಕ್ಷದ ವ್ಯವಸ್ಥೆಗಳ ಉಲ್ಲೇಖಗಳು, ಸಂಬಂಧವನ್ನು ಸೂಚಿಸುವುದಿಲ್ಲ ಅಥವಾ ವ್ಯಕ್ತಪಡಿಸುವುದಿಲ್ಲ. AGRO-AI ಮತ್ತು ಮೂರನೇ ವ್ಯಕ್ತಿಯಿಂದ ಬರವಣಿಗೆಯಲ್ಲಿ.

5. ಕೃಷಿ ನಿರ್ಧಾರಗಳು ಮತ್ತು ಜವಾಬ್ದಾರಿ

AGRO-AI ನಿರ್ಧಾರ-ಬೆಂಬಲ ಸಾಫ್ಟ್‌ವೇರ್, ವಿಶ್ಲೇಷಣೆ, ಶಿಫಾರಸುಗಳು, ವರದಿಗಳು ಮತ್ತು ವರ್ಕ್‌ಫ್ಲೋ ಪರಿಕರಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ. AGRO-AI ವೃತ್ತಿಪರ ತೀರ್ಪು, ಕ್ಷೇತ್ರ ವೀಕ್ಷಣೆ, ಕೃಷಿ ಪರಿಣತಿ, ಎಂಜಿನಿಯರಿಂಗ್ ವಿಮರ್ಶೆ, ಕಾನೂನು ಸಲಹೆ, ನಿಯಂತ್ರಕ ಪರಿಶೀಲನೆ ಅಥವಾ ಕಾರ್ಯಾಚರಣೆಯ ಜವಾಬ್ದಾರಿಯನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ.

ಬಳಕೆದಾರರು ಅವುಗಳ ಮೇಲೆ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಮೊದಲು AGRO-AI ಔಟ್‌ಪುಟ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸಲು ಜವಾಬ್ದಾರರಾಗಿರುತ್ತಾರೆ.

ನೀರಾವರಿ, ನೀರು-ಬಳಕೆ, ಉಪಕರಣಗಳು, ಕ್ಷೇತ್ರ ಕಾರ್ಯಾಚರಣೆಗಳು, ಅನುಸರಣೆ ಮತ್ತು ಸಂಪನ್ಮೂಲ-ನಿರ್ವಹಣೆಯ ನಿರ್ಧಾರಗಳು ಹವಾಮಾನ, ಮಣ್ಣು, ಬೆಳೆ ಪರಿಸ್ಥಿತಿಗಳು, ಮೂಲಸೌಕರ್ಯ ಮಿತಿಗಳು, ಸ್ಥಳೀಯ ನಿಯಮಗಳು, ಡೇಟಾ ಗುಣಮಟ್ಟ ಮತ್ತು ಮಾನವ ತೀರ್ಪುಗಳಿಂದ ಪ್ರಭಾವಿತವಾಗಿರುತ್ತದೆ. AGRO-AI ಔಟ್‌ಪುಟ್‌ಗಳನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುವ ಮೊದಲು ಪರಿಶೀಲಿಸಬೇಕು.

AGRO-AI ಡೇಟಾವನ್ನು ಸಂಘಟಿಸಲು, ವರದಿಗಳನ್ನು ರಚಿಸಲು, ಪುರಾವೆಗಳನ್ನು ತಯಾರಿಸಲು ಮತ್ತು ಅನುಸರಣೆ ವರ್ಕ್‌ಫ್ಲೋಗಳನ್ನು ಬೆಂಬಲಿಸಲು ಸಹಾಯ ಮಾಡಬಹುದು. AGRO-AI ಯಾವುದೇ ಏಜೆನ್ಸಿ, ಜಿಲ್ಲೆ, ನಿಯಂತ್ರಕ, ಗ್ರಾಹಕ ಅಥವಾ ಮೂರನೇ ವ್ಯಕ್ತಿಯಿಂದ ನಿಯಂತ್ರಕ ಅನುಸರಣೆ, ಆಡಿಟ್ ಅನುಮೋದನೆ, ಪರವಾನಗಿ ಅನುಮೋದನೆ, ಕಾನೂನು ಸಮರ್ಪಕತೆ ಅಥವಾ ಸ್ವೀಕಾರವನ್ನು ಖಾತರಿಪಡಿಸುವುದಿಲ್ಲ.
